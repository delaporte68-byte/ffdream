Grille et Déplacement

1 case = 1 mètre — Le canvas Foundry est calibré pour que chaque cellule de grille corresponde à 1 mètre en jeu. Le déplacement maximum d'un personnage est calculé comme : 2 + valeur Athlétisme mètres par tour.

Style CHM — 5 Variantes

Choix Multiple (CHM)

Quand une technique de style chm est utilisée, un dialogue s'ouvre avec jusqu'à 5 variantes (slots chm.slot1 à chm.slot5), chacune ayant son propre style, dégâts, effets et animations. Le joueur choisit quelle variante exécuter.

Style AOE — 3 Jets Séquentiels

Le style aoe effectue 3 jets de dé successifs contre 3 seuils décroissants :

1er jet : seuil 60 → 2ème jet : seuil 50 → 3ème jet : seuil 40

Chaque succès inflige des dégâts. Les 3 impacts sont affichés dans le chat Foundry.

Calcul de la Réduction (Esquive & Défense)

Formule
Seuil = Jet attaquant + Compétence défenseur
1d100 vs seuil → Marge = Résultat − Seuil
MargeRéduction des dégâts
Marge > 00% — Réaction ratée
Marge ≥ −1540% des dégâts évités
Marge ≥ −2550% des dégâts évités
Marge < −25 ou critique (jet ≤ 5)100% — Esquive/Défense parfaite
Les réactions sont réinitialisées à chaque nouveau tour (hook combatRound dans FFdreameCombatSystem). Chaque réaction ne peut être utilisée qu'une fois par tour.

Structure

  • Nom configurable
  • 1 effet de tableau associé

10
Zones de Canalisation

Déclenchement

Une technique déclenche une zone de canalisation si elle cumule 3 conditions :

  • system.style = "multis"
  • system.surSoi = true
  • system.canalisation = true

Cliquer le slot en combat bascule la zone ON/OFF (toggle). Un token sélectionné sur le canvas est requis.

Comportement

  • Zone circulaire centrée sur le token lanceur, rayon = system.multi.largeur mètres
  • Animation Sequencer persistante attachée au token — suit le lanceur si il se déplace
  • Détection d'entrée/sortie automatique via hook updateToken
  • Tous les 19 types d'effets peuvent être appliqués aux tokens dans la zone
  • Effets périodiques (dot, ponction, ponctionm) déclenchés à chaque round
  • canalisationPM PM consommés par round — arrêt auto si PM insuffisant
  • Suppression du token lanceur → zone stoppée automatiquement

API Publique

Autres Systèmes de Combat

Zones Persistantes (FFdreamePersistentZones)

  • Zones placées sur la map qui infligent des dégâts chaque round
  • Disparaissent après N rounds configurés (animation.dureeTours)
  • Déclenchées via animation.persistante = true sur une technique

Multi-zones (Style MULTI)

  • AOE classique avec prévisualisation canvas (PIXI)
  • Types : cercle ou ligne
  • Validation de la distance max avant le lancer
  • Dégâts dégressifs : 1er token 100%, 2ème 80%, 3ème 60%…

AOER — Zone Différée

  • Marque une zone visuelle sur le terrain (template Foundry)
  • Se déclenche automatiquement au round suivant
  • Formes disponibles : cercle, ligne, triangle
  • Paramètres : aoer.forme, aoer.distanceMax, aoer.taille, aoer.angle

Téléportation (FFdreameTeleportation)

TypeComportement
lanceurDéplace le personnage autour de la cible (positions : derrière, devant, gauche, droite)
cibleLe joueur clique pour choisir la destination de téléportation

Validation automatique de la distance max (teleportation.distanceMax).

Token HUD (FFdreameTokenHUD)

  • Haut du token : Points d'action (PA dots) — cercles verts/rouges
  • Gauche : Barre Burste (⚡ orange)
  • Droite : Barre PM (mauve)

Barre de Combat (FFdreameCombatBar)

Barre fixe de 960px en bas d'écran, visible uniquement en combat :

  • Portrait du personnage actif
  • Bouton de ciblage
  • Bouton "Fin de Tour"
  • Affichage des PA (cliquables)
  • Boutons Tableau 1 / Tableau 2
  • Boutons Réactions (Esquive / Défense / Marche)
  • Techniques rapides (depuis les slots des tableaux)

Barre d'Initiative (FFdreameInitiativeBar)

Barre horizontale en haut de l'écran, style Baldur's Gate 3 :

  • Portraits des combattants dans l'ordre d'initiative
  • Mise en surbrillance du combattant actif
  • Clic → pan de la caméra vers le token correspondant

Notifications (FFdreameNotifications)

  • Style "Baldur's Gate 3" — carrés colorés apparaissant en coin d'écran
  • Succès critique : notification verte avec ⭐
  • Échec critique : notification rouge avec 💀
  • Tour d'un joueur : notification dédiée avec son nom
  • ULTIMATE disponible : notification spéciale 🔥

Déplacement (FFdreameMovement + FFdreameMovementBlocker)

Distance max = 2 + valeur Athlétisme (mètres)
  • En combat : 1 déplacement gratuit par tour
  • Réaction "Marche" = déplacement supplémentaire
  • Validation à preUpdateToken — empêche tout déplacement illégal
  • Si Athlétisme change → mise à jour automatique de la distance token
  • Drag Ruler intégré (si le module est installé)

Combat System (FFdreameCombatSystem)

MomentAction
Début de combatInitialise tous les combattants (PA, réactions, déplacement)
Nouveau roundRestaure 1 Grand PA par personnage, réinitialise réactions et déplacement gratuit
Fin de combatNettoie tous les flags, zones de canalisation, effets temporaires

GM Tracker
Le GM Tracker est un acteur de type gm-tracker. Il n'a pas de token sur le canvas, c'est un panneau de contrôle centralisé pour le Game Master.

Fonctionnalités

Supervision en temps réel
  • Barres PV / PM / Burste de chaque joueur
  • Cases Fatigue (f1–f9) modifiables directement
  • Cases Blessures (b1–b9) modifiables directement
  • Auto-refresh quand n'importe quel acteur est modifié
Contrôle du combat
  • Contrôle PA individuel (reset, toggle petits PA)
  • Blocage/déblocage d'actions (stun) par joueur
  • Bouton "Nouveau Tour" → restaure PA pour tous
  • Mode dés : toggle Auto / Manuel

Mode Dés Manuel

Paramètre système : ffdreame.manualDiceMode

  • Auto (défaut) → Foundry lance les dés automatiquement
  • Manuel → Le MJ entre les résultats à la main dans une boîte de dialogue

En tant que Développeur

Ajouter des Styles

Dans actor-sheet.js, méthode _useTableTechnique() — ajouter un nouveau case ou bloc if avec la logique de calcul.

Ajouter des Effets

Dans actor-sheet.js, méthode _appliquerEffet() — ajouter le nouveau type dans le switch.

Nouveaux Acteurs

Enregistrer dans ffdreame.js via Actors.registerSheet(), ajouter dans template.json la structure de données.

Nouvelles Animations

Ajouter l'entrée dans le <select> du template technique-sheet-v2.html.
